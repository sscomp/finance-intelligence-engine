# M6 — 投資組合報告

## Problem / Context

Phase 5 M2–M5 完成了投資組合的領域模型、風險引擎、配置引擎與執行規劃，但缺少一個將所有元件整合為結構化報告的模組。投資人需要一份可讀的報告來理解配置建議、風險狀態與執行計畫。

## Decision

建立 `phase3/portfolio/report.py` 模組與 `portfolio-report` CLI 子命令，將 Pipeline 結果、配置建議、風險指標與執行計畫整合為 Markdown + JSON 雙格式報告。

### 範圍

- `PortfolioReport` dataclass：包含 allocation、risk、execution 三個區段
- `portfolio-report --date <range>` CLI：從 pipeline artifact 讀取，產出報告
- 安全守護繼承 M3/M4 的 TD7/TD8 限制

## Consequences / Trade-offs

- **正面**：投資人獲得結構化、可讀的報告輸出；JSON 格式支援程式化後處理
- **取捨**：`from_dict` 僅支援 2 層 section nesting（設計範圍，非缺陷）
- **安全**：不修改任何受保護檔案、DB、SSOT 或 cron jobs

## Validation / Evidence

- Gate G-P5-6：`portfolio-report --date <range>` 產出有效 MD + JSON — PASS
- Targeted tests + full regression 全部 PASS
- 獨立審查：PASS WITH CAVEATS（2 個 non-blocking caveats）
